# 人生记忆树 · 微信小程序工程

这是原生微信小程序源码，包含 WXML、WXSS、JavaScript、云函数及权限规则。**工程已实现，尚未绑定真实 AppID、部署云资源或提交微信审核。**

## 现在可以做什么

- 文字与一张照片记录，六种记忆类型，手动填写日期、人物、地点及「写给未来的我」。
- 人生树、年月筛选、全文搜索、珍贵记忆筛选和基于真实记录的回望。
- 编辑、删除、恢复新记录的文字草稿，修改冲突提示与失败重试。
- 微信身份隔离的云端记录；私有照片；导出与导入文字 JSON；清空个人记录。
- 图片选择的隐私授权组件、数据说明页、全量删除与照片清理重试。

当前没有支付、公开社区、记忆分享、定位、手机号收集或生成式 AI。回望不会编造用户经历。

## 1. 准备自己的小程序账号

在 [微信公众平台](https://mp.weixin.qq.com/) 注册或使用已有小程序，确认个人或企业主体、名称与可选服务类目。账号资料、资质和备案应按后台的实际要求填写。

打开微信开发者工具，选择「导入项目」，目录选本文件所在文件夹，使用自己的 AppID。源码的 `touristappid` 只用于无账号时查看页面，不支持云端保存，不可用来上传正式版本。

## 2. 填写配置

1. `project.config.json` 的 `appid`：正式的 `wx…` AppID。
2. `miniprogram/config.js` 的 `envId`：已关联本小程序的微信云开发环境 ID。
3. 同文件的 `operator`、`contactEmail`：真实运营主体与可处理隐私请求的邮箱。
4. 同文件的 `filingNumber`：完成备案后填写真实备案号，展示在「我的」。

**客户端不需要 AppSecret，也不要把 AppSecret、腾讯云密钥或代码上传私钥填进源码。**

## 3. 部署云开发

1. 在微信开发者工具开通云开发并创建环境；若使用既有环境，确认其与 AppID 的关联。正式使用的套餐、费用和地区以控制台为准，未授权前不要购买套餐。
2. 创建数据库集合 `life_memories`。
3. 集合权限设为「仅管理端可读写」，对应 `database.rules.json`。前端只通过云函数读写，云函数从 `getWXContext().OPENID` 获取身份，不接受客户端声明的所有者。
4. 创建索引：`_openid ASC, deleted ASC, _id ASC`；`_openid ASC, deleted ASC, photoFileId ASC`；以及 `_openid ASC`。若提示已有前缀索引，以控制台结果为准。不要建立全局唯一的 `_openid` 索引。
5. 云存储选择「仅创建者可读写」，或在支持自定义规则的控制台粘贴 `storage.rules.json`。**不要保留所有用户可读的默认照片权限。**权限依赖上传者身份元数据，不是仅依赖文件路径。必须用两个微信测试账号验证。
6. 右键 `cloudfunctions/memories` →「上传并部署：云端安装依赖」。函数名必须为 `memories`，使用控制台支持的 Node.js 运行时。SDK 固定为 `wx-server-sdk@4.0.2`。函数超时建议设为 60 秒，供批量删除使用。
7. 检查函数成功部署、集合/索引/存储规则生效，再开始真机测试。工程使用 `wx.cloud.callFunction`，无需把网页域名配置成业务域名。

参考：[云开发环境创建](https://docs.cloudbase.net/quick-start/create-env)、[微信小程序云函数](https://docs.cloudbase.net/recipes/add-cloud-function-wechat-miniprogram)、[数据库安全规则](https://docs.cloudbase.net/database/security-rules)、[存储安全规则](https://docs.cloudbase.net/storage/security-rules)。具体控制台和基础库兼容性需要实际账号复核。

## 4. 隐私与发布资料

在微信公众平台配置与代码一致的用户隐私保护指引，覆盖微信用户标识、主动填写的内容、所选择的照片，以及文字导入的聊天文件选择能力。根据平台提示声明 `chooseMedia`、`chooseMessageFile` 等实际使用的接口。拒绝照片授权应仍能保存文字。

应用内说明已写好，但运营主体、联系方式、数据存储地区、服务商/备份保留与删除周期，应按实际环境完善并审核。代码没有端到端加密，不应对外宣传「开发者也无法读取」。

建议简介：**用文字和照片记录值得记住的瞬间，让回忆长成人生树。按年月回望，珍藏日常、喜悦与成长。**

建议审核备注：本产品为私人记录工具；用户主动填写文字并可选上传一张照片，仅本人可查看；无公开社区与记忆转发。审核路径：首页开始使用 → 留下 → 保存文字/照片 → 人生树 → 详情编辑 → 回望 → 我的导出或删除。

## 5. 真机验收后提交

至少用 iOS、Android 各一台真机验证：

- 新用户空状态；拒绝照片权限后保存文字；图片选择/预览。
- 创建后退出再进入仍存在；同一微信另一设备能读取。
- 两个账号相互看不到文字和照片；复制他人记录 ID/照片 ID 不可越权。
- 跨年日期、闰日、月份切换、搜索、珍贵标记、修改与删除。
- 弱网保存失败不显示成功；连续点击无重复创建；两台设备修改产生冲突提示。
- 导出文字、重新导入同一备份、清空与照片清理重试。
- 大字体、键盘遮挡、刘海屏、安全区、隐私弹窗与返回导航。

在微信开发者工具编译、真机调试后「上传」，微信公众平台选该开发版本为体验版；完成备案、名称/类目/隐私资料、体验验收后提交审核，审核通过再发布。**Sites 网页发布不等于微信小程序发布，微信的审批结果不能由代码保证。**

## 数据与备份

小程序数据存于你配置的腾讯云环境。网页数据存于其当前浏览器，两者不会自动同步。

「我的 → 导出文字记录」导出 JSON，不含照片。重要照片需在详情中预览后另行保存；导入也仅导入文字，不会从网页备份上传照片。导入最多 300 条、5MB。网页版完整备份含照片，原文件应单独保存。重复导入同一来源备份可重试，既有数据不会覆盖。

单条删除先隐藏记录，再删除文件；文件清理失败保留待清理记录并提示，可通过「我的 → 重试已删除照片的清理」继续。文件上传成功但用户未完成保存或会话中断，可能留下未关联的私有文件；正式运营应定期将云存储清单与 `life_memories.photoFileId` 对账，在保留恢复窗口并核实归属后清理。不要盲目清空存储桶。
